# MOOP

**Designed by Mishal.** A WHOOP-style iPhone app for your own WHOOP strap, offline, with your data kept on your phone.

This repo only hosts the finished iPhone app (`.ipa`) and the SideStore / AltStore source. The source code is private.

## Install on iPhone (SideStore / AltStore)

1. Set up **SideStore** (or AltStore) on your iPhone once: https://sidestore.io
2. In SideStore: **Sources → +** and paste:
   ```
   https://raw.githubusercontent.com/1414mishal/moop-app/main/altstore-source.json
   ```
3. Open the MOOP source and tap **Install**. New versions show up as updates.

Or download `MOOP.ipa` from [Releases](https://github.com/1414mishal/moop-app/releases) and open it with SideStore.
